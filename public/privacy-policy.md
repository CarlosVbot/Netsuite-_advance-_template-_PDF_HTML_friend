# Política de privacidad de NetSuite Advanced Template PDF/HTML Friend

**Última actualización:** 30 de julio de 2026

NetSuite Advanced Template PDF/HTML Friend respeta la privacidad de sus usuarios. Esta política explica cómo la extensión procesa la información y qué datos puede almacenar.

## 1. Descripción de la extensión

NetSuite Advanced Template PDF/HTML Friend es una herramienta para formatear, analizar, validar, comparar y exportar plantillas Advanced PDF/HTML utilizadas en NetSuite.

La extensión procesa plantillas que pueden contener código XML, HTML, CSS, etiquetas BFO y directivas de FreeMarker.

## 2. Procesamiento local de las plantillas

Todo el contenido pegado o escrito en el editor se procesa localmente dentro del navegador del usuario.

Las plantillas:

* No se envían a servidores externos.
* No se transmiten al desarrollador.
* No se comparten con terceros.
* No se utilizan para publicidad.
* No se utilizan para análisis de comportamiento.
* No se utilizan para entrenar modelos de inteligencia artificial.
* No son revisadas manualmente por el desarrollador.

El análisis, formato, validación, comparación y exportación se realizan directamente en el dispositivo del usuario.

## 3. Información almacenada localmente

La extensión puede utilizar `chrome.storage.local` para guardar preferencias de funcionamiento, como:

* Tema visual.
* Tamaño de fuente del editor.
* Tipo de indentación.
* Tamaño de los paneles.
* Última vista seleccionada.
* Preferencia de guardado automático.

Estas preferencias permanecen dentro del navegador del usuario y no se transmiten al desarrollador ni a servicios externos.

## 4. Guardado del contenido del editor

De manera predeterminada, la extensión no guarda permanentemente el contenido de las plantillas pegadas en el editor.

La extensión puede ofrecer una opción llamada:

**“Guardar automáticamente el contenido del editor”**

Esta opción está desactivada de forma predeterminada.

Cuando el usuario la activa voluntariamente, el contenido puede almacenarse localmente en su navegador para recuperarlo posteriormente. Incluso en ese caso, el contenido no se envía a servidores externos.

El usuario puede desactivar esta función y eliminar el contenido almacenado desde la configuración de la extensión.

## 5. Datos personales

NetSuite Advanced Template PDF/HTML Friend no solicita ni recopila intencionalmente:

* Nombre.
* Dirección.
* Número telefónico.
* Correo electrónico.
* Credenciales de NetSuite.
* Contraseñas.
* Cookies de sesión.
* Información bancaria.
* Información de pago.
* Historial de navegación.
* Direcciones IP.
* Datos de ubicación.
* Datos biométricos.

La extensión no requiere que el usuario cree una cuenta o inicie sesión.

## 6. Datos de NetSuite

La extensión no se conecta directamente a una cuenta de NetSuite.

No accede a:

* Registros de NetSuite.
* Sesiones activas.
* Cookies de autenticación.
* Roles o permisos.
* Búsquedas guardadas.
* Suitelets o RESTlets.
* Archivos del File Cabinet.
* Información empresarial almacenada en NetSuite.

El contenido de una plantilla solamente se procesa cuando el usuario lo pega o escribe voluntariamente en el editor.

Las plantillas pueden contener nombres de campos, identificadores internos u otra información perteneciente a la cuenta de NetSuite del usuario. Esa información permanece localmente en el navegador y no se transmite al desarrollador.

## 7. Permisos del navegador

La extensión puede solicitar el permiso `storage` exclusivamente para guardar preferencias y, cuando el usuario lo autorice, el contenido del editor.

La extensión no utiliza permisos para acceder a:

* Cookies.
* Historial de navegación.
* Pestañas abiertas.
* Actividad web.
* Cámara.
* Micrófono.
* Ubicación.
* Portapapeles sin una acción explícita del usuario.

Las operaciones de copiar o descargar contenido solamente se ejecutan cuando el usuario presiona el botón correspondiente.

## 8. Servicios externos y terceros

La extensión no utiliza:

* Servicios de analítica.
* Redes publicitarias.
* Herramientas de seguimiento.
* Telemetría.
* APIs externas.
* Scripts cargados desde CDN.
* Servicios externos para procesar las plantillas.

La extensión puede incluir un enlace opcional a Ko-fi para apoyar voluntariamente el proyecto.

Al seleccionar ese enlace, el usuario abandona la extensión y accede al sitio web de Ko-fi. La información proporcionada en ese sitio se procesa de acuerdo con la política de privacidad y los términos de Ko-fi.

NetSuite Advanced Template PDF/HTML Friend no recibe ni almacena los datos de pago introducidos en Ko-fi.

## 9. Compartición o venta de información

La extensión no vende, alquila, licencia ni comparte información del usuario con terceros.

La información procesada por la extensión no se utiliza para:

* Publicidad personalizada.
* Seguimiento entre sitios.
* Elaboración de perfiles.
* Evaluación crediticia.
* Marketing.
* Reventa de datos.

## 10. Conservación y eliminación de datos

Las preferencias guardadas localmente permanecen en el navegador hasta que ocurra alguna de las siguientes acciones:

* El usuario restablece la configuración.
* El usuario utiliza la opción “Eliminar datos locales”.
* El usuario elimina los datos de la extensión desde Chrome.
* El usuario desinstala la extensión.

El desarrollador no puede recuperar el contenido eliminado, ya que no mantiene copias externas ni bases de datos con dicha información.

## 11. Seguridad

La extensión está diseñada para procesar el contenido como texto y evitar que las plantillas pegadas ejecuten código dentro de la aplicación.

No se utiliza `eval`, código JavaScript remoto ni ejecución dinámica de contenido proporcionado por el usuario.

Aunque ninguna aplicación puede garantizar una seguridad absoluta, la extensión reduce el riesgo al mantener el procesamiento y almacenamiento dentro del navegador del usuario.

## 12. Privacidad de menores

La extensión está dirigida a desarrolladores, administradores y consultores que trabajan con plantillas de NetSuite.

No está dirigida específicamente a menores de edad y no recopila intencionalmente información personal de menores.

## 13. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de la extensión, sus permisos o sus prácticas de procesamiento de información.

Cuando se realicen cambios, la fecha indicada al inicio de esta política será actualizada.

Cualquier cambio importante relacionado con la recopilación, transmisión o uso de información será comunicado mediante la ficha de Chrome Web Store o dentro de la extensión cuando corresponda.

## 14. Relación con NetSuite y Oracle

NetSuite Advanced Template PDF/HTML Friend es un proyecto independiente.

No está afiliado, patrocinado, certificado ni respaldado por Oracle Corporation o NetSuite.

NetSuite y Oracle son marcas registradas de sus respectivos propietarios.
